| F1  | На сайте новый клиент видит список доступных депозитов с актуальными ставками и подаёт заявку (ФИО, телефон). | F5  | Бэк-офис депозитов согласовывает условия депозита по заявке (на этапе MVP — вручную через АБС)                                                                                                          | *Из постановки.* В MVP сохраняется текущий процесс с участием бэк-офиса; автоматизация — целевое состояние через год.                                                                      |

| F7  | Клиент получает СМС-уведомления: после согласования ставки бэк-офисом и после открытия депозита                                                                                                         | *Из постановки.* Реализуется силами команды банка, а не подрядчика ИБ — см. +R6.                                                                                                            |
| F8  | Запись и просмотр обращения клиента (с сайта или из ИБ) в системе кол-центра банка для дальнейшей работы менеджеров                                                                                       | *Из постановки.*                                                                                                                                                                            |

| U2  | Соответствие корпоративной системе дизайна банка: фирменные цвета, брендированные элементы, типографика                                                                                                | *Из постановки.* Применимо к сайту и ИБ.                                                                                                                                                    |

| U4  | Базовый уровень доступности (a11y) клиентских интерфейсов: контраст, размер шрифта, поддержка клавиатурной навигации                                                                                     | *Добавлено.* Целевая аудитория расширяется до молодой, но не вытесняет существующую — пожилых клиентов; банковские сервисы в РФ ориентируются на рекомендации ЦБ по доступности.            |

| R4  | RPO ≤ 5 мин и RTO ≤ 15 мин для нового сервиса заявок на депозит                                                                                                                                          | *Добавлено.* В постановке нет конкретных цифр; стандартная для банковского онлайн-канала метрика, влияющая на стратегию репликации БД и резервирования.                                     |
| R5  | Гарантированная доставка событий (заявок и СМС-уведомлений) между системами с подтверждением, без потери при сбое одного из узлов                                                                        | *Добавлено.* СМС-уведомление о ставке/открытии депозита и заявка с сайта — критичные сообщения; их потеря приводит к жалобам клиентов и регуляторным рискам.                              |

| P2  | Горизонтальное масштабирование сервисов нового онлайн-процесса депозитов и фронтенда интернет-банка; равномерное распределение запросов между серверами/ЦОД                                              | *Из постановки.*                                                                                                                                                                            |
